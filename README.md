# Freedom IPTV

A fast, modern IPTV player for Android and Android TV.

## Goals

- Fast startup and channel switching
- Xtream Codes API and M3U playlist support
- Media3 / ExoPlayer playback
- Cached, indexed channel catalog and EPG
- Favorites, recent channels, and channel groups
- Responsive dark UI for mobile and TV
- Secure local credential storage

## Project status

Repository initialized. Implementation roadmap:

1. Android app foundation and Media3 player lifecycle
2. Xtream Codes and M3U provider adapters
3. Incremental playlist ingestion and Room database
4. Fast channel guide, favorites, and recents
5. EPG ingestion and lookup
6. Android TV remote navigation and playback UX
7. Performance benchmarks and release automation

## Privacy & legal

Use only playlists and streams you are authorized to access. Provider credentials should remain on-device and must never be committed to source control.
